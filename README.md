# 하루에 다 끝내는 자연어 분석 서머리 노트 — 저녁반

AI 연구실 해설 · 쪽지시험 대비 · 비전공자용

**바로 보기:** https://adminmrobo.github.io/LLM_summary_note/ · 부록 실전 연습장 https://adminmrobo.github.io/LLM_summary_note/practice/

내일이 박사의 쪽지시험입니다. 오전에 머신러닝, 오후에 딥러닝을 마친 인턴 시아와 모아가 저녁에는 자연어 분석 범위를 여섯 교시 14단계로 정리합니다. 조수 하루가 수식을 대신 묻고, 초파리 연구원이 함정을 짚고, 주판봇이 숫자를 셉니다. 교시가 끝날 때마다 박사가 쪽지시험 네 문제를 내고, 종례에는 모의 면접을 봅니다. **단계마다 게임이나 시연이 하나씩** 있고, 맨 끝 부록에서 가상 쇼핑몰을 직접 운영합니다.

## 구성 (index.html)

| 교시 | 단계 | 내용 | 게임·시연 |
|---|---|---|---|
| 1교시 사람 말을 읽는 컴퓨터 | 1~2 | NLP의 뜻·과제·세 시대, 여덟 걸음 파이프라인 | 과제 맞히기 8장면, 후기 한 줄의 여덟 걸음 여행(고전·현대·LLM) |
| 2교시 글 다듬고 자르기 | 3~4 | 전처리·불용어·어간/표제어, 토큰화·서브워드 | 다듬기 스위치로 감정 판정 지키기, 작은 BPE 사전 만들기 |
| 3교시 글자를 숫자로 | 5~7 | 단어 주머니·n-그램, TF-IDF, 임베딩·코사인 | 순서만 다른 두 후기, 낱말 무게 달기, 장난감 뜻의 지도 + 가까운 말 게임 |
| 4교시 글에 딱지 붙이기 | 8~9 | 감성 분류(TF-IDF + 로지스틱), 개체명·품사 | 모델 속이기(AI 판단 코너), 형광펜 개체 칠하기 + 개체 단위 F1 |
| 5교시 트랜스포머와 LLM | 10~11 | RNN→트랜스포머·셀프 어텐션, BERT·GPT·LLM 맞춰 쓰기 | "배"는 누구를 볼까, 작은 언어 모델(이어 쓰기·가린 말·적응 방법) |
| 6교시 찾고, 재고, 쓰기 | 12~14 | 유사도·검색·주제, 평가 지표, 현장 실수 | 문의 묶기와 검색, 판정 뒤집기 채점표, 실수 고치기 6장면 |
| 종례 | — | 면접 11문항 | 뒤집는 카드 + 확인 6문제 |

그 밖에 성적표(30문제), 치트시트(과제 → 시작 방법), 14단계 정리 표, 지식 색인, 온톨로지·서지 꾸러미가 있습니다.

## 부록 실전 연습장 (practice/index.html)

가상 쇼핑몰 "모아마켓"의 세 장면. 초록 상자는 환경, 파랑 상자는 내 결정입니다. 장면마다 미션 셋(최적 찾기 / 함정 관찰 / 환경을 바꿔도 결론 유지).

1. **가게 후기판** — 부정어 지키기·두 낱말 묶음·판정 문턱으로 불만 후기 F1 올리기
2. **고객센터** — TF-IDF와 뜻 사전, 문턱으로 같은 문의 묶기
3. **사내 챗봇(RAG)** — 검색 방법·건넬 문서 수 k·"모른다" 답하기로 정답률과 비용 맞추기

주소 끝에 `#shop`, `#desk`, `#bot`을 붙이면 그 장면이 바로 열립니다.

## 자료와 숫자

- 범위와 순서는 사용자가 제공한 NLP 노트 그림 18장(Ali Data Analytics 표기)을 바탕으로 했습니다. 예제 문장은 모두 한국어로 새로 만들었습니다.
- 6단계(TF-IDF 0.60·0.46)와 13단계(0.75)는 원 노트 숫자가 그대로 나오도록 같은 구조로 만들었고, scikit-learn 1.9.1로 원 노트 숫자를 재현해 검산했습니다.
- 화면의 숫자는 페이지 안에서 계산합니다(외부 라이브러리 없음). 원 노트와 다르게 쓴 곳은 페이지 바닥글에 적었습니다.
